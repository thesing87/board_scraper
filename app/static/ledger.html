YeYe홈 앱 받기

관리자가 앱 파일을 올리면 여기서 받을 수 있어요

설치 방법
  1. YeYe홈 앱 받기 → 설치 ('출처를 알 수 없는 앱' 허용)
  2. 앱에서 알림 읽기 권한 켜기 (회색이면 앱 정보 → ⋮ → '제한된 설정 허용')
  3. 앱에서 가계부 설정 → 휴대폰 연결 → 연결하기
  4. 시험 알림 보내기 → 확인할 결제에 뜨면 끝
연결 주소 (매크로드로이드용)

  1. 매크로드로이드 → 새 매크로 → 트리거 알림 받음 (카드사·문자 앱)
  2. 동작 HTTP 요청: POST, 주소는 위 연결 주소, 본문 [notification]

주소는 다른 사람에게 보여 주지 마세요. 집 밖에서도 보내려면 바깥 주소(DDNS)로 연 뒤 만드세요.
