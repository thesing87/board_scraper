내 휴대폰 연결

휴대폰의 결제 알림을 아래 연결 주소로 보내면 내 이름으로 확인 대기함에 쌓여요. 주소는 다른 사람에게 보여 주지 마세요.

알림 읽기 권한 · 연결 주소 · 무시할 알림 · 최근 알림
YeYe홈 앱 받기

관리자가 'YeYe홈' 앱 파일을 올리면 여기서 받을 수 있어요.

  1. 휴대폰에서 YeYe홈 앱 받기 → 설치 ('출처를 알 수 없는 앱' 허용)
  2. 앱에서 알림 읽기 권한 켜기 — 회색이면 앱 정보 → ⋮ → '제한된 설정 허용' 뒤 다시
  3. 위 연결 주소를 복사해 앱의 붙여넣기
  4. 앱의 시험 알림 보내기 → 이 페이지 확인 대기함에 뜨면 끝
앱 대신 매크로드로이드로
  1. 매크로드로이드 앱 설치 → 새 매크로
  2. 트리거: 알림 → 알림 받음 → 카드사 앱·문자 앱 고르기 (내용에 "승인" 포함으로 걸러도 좋아요)
  3. 동작: HTTP 요청 → 방식 POST, 주소는 위 연결 주소, 본문은 [notification] (알림 내용)
  4. 카드 결제를 하거나 위 '시험 알림 보내기'로 대기함에 뜨는지 확인

집 밖에서도 보내려면 이 페이지를 바깥 주소(DDNS)로 연 뒤 연결 주소를 만드세요.

가게 이름에 이 글자가 있으면 분류를 미리 골라요 (모두 함께 씀)
